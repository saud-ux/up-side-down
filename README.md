# إيموجي — خمّن من الرموز

لعبة تفاعلية عربية — الهوست يحط إيموجيات تمثل شيء معين واللاعبين يخمنون. تدعم اللعب من المتصفح ومن شات تويتش.

## التشغيل

```bash
npm install
npm start
```

السيرفر يشتغل على `http://localhost:3000`

## الصفحات

| الصفحة | الرابط | الوصف |
|--------|--------|-------|
| الهوست | `/` | إنشاء الغرفة وإدارة اللعبة |
| اللاعب | `/play.html` | الانضمام والتخمين |
| الأوفرلاي | `/overlay.html` | عرض OBS بخلفية شفافة |

## كيف تلعب

1. الهوست يفتح الصفحة الرئيسية وينشئ غرفة
2. اللاعبين ينضمون بالكود أو الرابط المباشر (`/play?room=XXXX`)
3. الهوست يحدد الإعدادات (عدد الجولات، وقت الجولة)
4. الهوست يكتب الإيموجيات والجواب (أو يختار من الاقتراحات الجاهزة) + الفئة كتلميح
5. تبدأ الجولة — الإيموجيات تظهر واللاعبين يخمنون
6. أول 3 إجابات صحيحة: 3، 2، 1 نقاط
7. الجولة تنتهي بعد 3 صح أو انتهاء الوقت
8. بعد كل جولة الهوست يحضّر جولة جديدة

## تويتش

- الهوست يدخل اسم القناة ويضغط اتصال
- `!join` أو `!انضم` للانضمام
- `!leave` أو `!انسحب` للمغادرة
- أي رسالة أثناء الجولة = محاولة تخمين
