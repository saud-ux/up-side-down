# كلمة مقلوبة

لعبة تفاعلية عربية — السيرفر يعرض كلمة مقلوبة واللاعبين يخمنون الكلمة الأصلية. تدعم اللعب من المتصفح ومن شات تويتش.

## التشغيل

```bash
npm install
npm start
```

السيرفر يشتغل على `http://localhost:3000`

## الصفحات

| الصفحة | الرابط | الوصف |
|--------|--------|-------|
| الهوست | `/` | إنشاء الغرفة وإدارة اللعبة |
| اللاعب | `/play.html` | الانضمام والتخمين |
| الأوفرلاي | `/overlay.html` | عرض OBS بخلفية شفافة |

## كيف تلعب

1. الهوست يفتح الصفحة الرئيسية وينشئ غرفة
2. اللاعبين ينضمون بالكود أو الرابط المباشر (`/play?room=XXXX`)
3. الهوست يحدد الإعدادات (عدد الجولات، الصعوبة، الوقت، التلميح)
4. تبدأ اللعبة — الكلمة تظهر مقلوبة واللاعبين يخمنون
5. أول 3 إجابات صحيحة: 3، 2، 1 نقاط
6. التلميح يكشف الحرف الأول بعد نصف الوقت (اختياري)

## تويتش

- الهوست يدخل اسم القناة ويضغط اتصال
- `!join` أو `!انضم` للانضمام
- `!leave` أو `!انسحب` للمغادرة
- أي رسالة أثناء الجولة = محاولة تخمين

## التقنيات

- Node.js + Express
- Socket.IO
- tmi.js
- Web Audio API (مؤثرات صوتية)
